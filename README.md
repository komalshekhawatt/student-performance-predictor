# Student Performance Analysis & Prediction

## Project Overview

An end-to-end data analysis and machine learning project focused on understanding student academic performance and predicting mathematics scores.

The project analyzes student demographic information, test preparation, lunch category, reading scores and writing scores to identify patterns in academic performance.

## Objectives

- Perform exploratory data analysis on student performance data
- Identify patterns associated with mathematics performance
- Analyze relationships between reading, writing and mathematics scores
- Compare regression models for mathematics score prediction
- Perform SQL-based analysis on student performance data
- Present insights through visualizations and dashboards

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- SQL
- Streamlit

## Dataset

The dataset contains information about:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Reading Score
- Writing Score
- Mathematics Score

## Data Analysis

The project includes exploratory analysis of student scores, test preparation, lunch category, parental education and relationships between reading, writing and mathematics scores.

## Data Preprocessing

- Missing value handling
- Numerical feature scaling
- Categorical feature encoding
- Train-test split
- Feature transformation using Scikit-learn pipelines

## Machine Learning

The project includes:

- Linear Regression
- Ridge Regression
- Random Forest Regression

The models are used to predict mathematics scores and evaluated using regression metrics.

## SQL Analysis

SQL queries are used to analyze student performance data and calculate useful statistics such as average scores and group-wise performance.

## Application

An interactive Streamlit application allows users to enter student information and obtain a predicted mathematics score.
