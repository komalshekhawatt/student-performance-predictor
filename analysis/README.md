# Exploratory Data Analysis

This folder contains exploratory analysis of the student performance dataset.

## Analysis Performed

- Dataset overview and data quality checks
- Score distributions
- Average mathematics, reading and writing scores
- Test preparation vs academic performance
- Parental education vs student performance
- Lunch category vs academic performance
- Correlation between reading, writing and mathematics scores

## Key Questions

1. How does test preparation relate to student performance?
2. How are reading and writing scores related to mathematics scores?
3. How does parental education relate to academic performance?
4. How does lunch category relate to student scores?
